# Window Assistance Controller

把窗口摆到你指定的位置并记住它，一键拉起整套应用并各自落位。

单文件、无依赖、无网络。C + Win32 实现，产物 `wac.exe` 约 480 KB，双击即用，默认以普通权限运行，不主动索要管理员权限。

---

## 为什么做这个

Windows 本身不提供跨会话的窗口位置记忆：换显示器、改分辨率、重启之后，窗口总会跑到别处去。

市面上已有的窗口管理工具，要么常驻后台轮询，要么注入 DLL，要么依赖特定运行框架。这个项目的目标很直接：用 C + Win32 写一个无依赖的单文件程序，按屏幕比例记住窗口位置，并且在显示器布局变化之后依然有效。

---

## 现在能做什么

| 能力 | 说明 |
|---|---|
| 窗口预设 | 让某个程序固定开在某个位置。按屏幕比例记录，换分辨率、换显示器都不会失效 |
| 自己双击也归位 | 你自己启动的程序，窗口出现后也会被自动摆回预设位置。不轮询，空闲零 CPU |
| 图形界面 | 窗口预设 / 工作区预设 / 设置 / 使用指南四个页面 |
| 命令行 | `place` / `apply` / `rules` / `run` / `close`，与界面共用同一份配置 |
| 全屏编辑 | 套用半屏、三等分、2×2、3×3 模板，或拖框自定区域；拖动与缩放调整区域；工具栏左端可直接改工作区名；[拾取当前布局] 把屏幕上的窗口反向记成预设；四条退出路径（Esc / 工具栏 / 热键 / 超时），退出后状态栏会说明是哪一条 |
| 工作区 | 一键拉起整套应用并各自落位；一键关闭这个工作区启动过的程序。槽位配置依赖全屏编辑 |

### 还没做的

- 编辑模式的精确尺寸输入
- 真实窗口预览（编辑模式目前用占位框显示程序名与尺寸）
- 显示器拔插后的自动恢复
- 工作区的槽位配置（依赖全屏编辑）

## 快速开始

### 构建

需要 Visual Studio 2022 + Windows SDK，x64：

```bat
build\build.cmd
```

### 运行

```bat
:: 无参数，打开主窗口
build\wac.exe

:: 或者直接用命令行
build\wac.exe place --launch notepad.exe --zone 0,0,0.5,1 --remember
build\wac.exe apply
```

首次运行可能被 SmartScreen 拦截。本程序未做代码签名，「Windows 已保护你的电脑」是未签名程序的正常提示，点「更多信息 → 仍要运行」，或者从源码自行编译。

遇到摆不动的窗口，那是它以管理员权限运行，Windows 不允许普通权限程序操作它的窗口。关掉本程序，右键「以管理员身份运行」即可。这是刻意设计，程序不会自己弹 UAC 要权限。

---

## 命令行

| 命令 | 作用 |
|---|---|
| `wac place` | 把指定窗口摆到指定区域 |
| `wac apply` | 应用所有已保存的预设 |
| `wac rules` | 查看与管理窗口匹配规则 |
| `wac run` | 按工作区拉起整套应用 |
| `wac close` | 关闭某个工作区启动过的程序 |

## 设计取舍

**按比例记录，不记像素。** 位置以 `0.3060, 0.3440, 0.6680, 0.6010` 这样的比例保存，而不是绝对像素。换分辨率、换显示器、缩放比例变化，预设依然落在视觉上相同的位置。

**事件驱动，不轮询。** 窗口出现依靠 WinEvent 回调触发，不需要忙等和定时器，空闲时 CPU 占用为零。

**不注入、不挂钩子。** 只用公开的 Win32 窗口 API。这既是安全边界，也是兼容性边界：不注入意味着不会因为目标进程的注入保护而崩溃，也不会被安全软件误报。

**不自行提权。** 需要操作管理员窗口时，由用户显式以管理员身份运行，而不是程序偷偷弹 UAC。

---

## 明确不做的事

不注入 DLL、不读其他进程内存、不装键盘钩子、不劫持注册表、不写启动项、不建计划任务、不联网（无网络代码、无自动更新、无遥测）、不加壳、不抓屏、不自行提权。

配置只写在 `%APPDATA%\WindowAssistanceController\`。可以断网运行全部功能。

## 项目结构

```
src/
  main.c            入口与主循环
  cli/              命令行子命令
  core/             窗口枚举、放置、显示器监听、规则应用
  model/            配置存储、工作区、运行状态
  ui/               主窗口、全屏编辑层、侧栏、设置页
  util/             日志、字符串、清理
res/                资源与清单文件
tests/              自动化测试（t00–t73）
build/              构建脚本
docs/               内部开发文档，不随仓库发布
```
